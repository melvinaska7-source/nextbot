# Nextbot School — этап 2

Большая карта-"школа" (коридор + 6 кабинетов, включая кабинет директора
и туалет), реальные текстуры стен/пола, Тишков вместо красного квадрата,
главное меню с музыкой, звук биорадара и поражения, защита от провала
сквозь пол.

## Управление

- Левый низ экрана — джойстик (ходьба).
- Правый верх экрана — свайп для поворота камеры.
- "БЕЖАТЬ" (удерживать) — спринт (скорость Тишкова).
- "ПРЫЖОК".
- Без спринта ходьба идёт на скорости трудички.

## Что нового по сравнению с этапом 1

- Карта выросла с 40×40 до полноценного здания ~56×30 с коридором и
  6 кабинетами (один жёлтый — "директорский", один — "туалет").
- У пола и стен теперь настоящие текстуры из твоего архива, плюс две
  картины на стенах коридора.
- Учитель — теперь спрайт с текстурой tishkov.png (билборд, всегда
  повёрнут к камере), а не квадрат.
- Есть главное меню (фон + кнопки "Играть"/"Настройки"/"Познакомиться")
  со своей музыкой, и громкость регулируется через "Настройки".
- В геймплее играет фоновая музыка, при приближении учителя звучит
  биорадар, при поимке — звук поражения плюс кнопки "ЗАНОВО" и "В МЕНЮ".
- Добавлена страховка от провала сквозь пол: если игрок или Тишков
  всё же куда-то провалились, их через мгновение вернёт на последнюю
  точку на земле (у Тишкова — на точку спавна).

## Про "Познакомиться"

Тексты персонажей я переписал мягче твоих оригинальных — убрал
оскорбления и сексуальные намёки в адрес реальных учителей, оставил
только игровые факты (сила/слабость). Изначальный текст с этим лучше
не выкладывать в приложение, которое может увидеть кто угодно.

## Как залить на GitHub с телефона (без ПК)

1. Создай новый пустой репозиторий на github.com.
2. Через **Working Copy** (iOS) / **Termux + git** / любой git-клиент
   под Android, который сохраняет структуру папок — залей содержимое
   архива целиком (включая assets/ и .github/workflows/).

## Как получить APK

Вкладка **Actions** в репозитории → workflow `build-android-apk`
соберётся сам за 3–7 минут. **Artifacts → nextbot-school-apk** →
скачать → установить (разреши "установку из неизвестных источников").
