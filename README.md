# Nextbot School — этап 1

Минимальный прототип: один учитель гонится за игроком по тестовой арене,
поимка = Game Over, кнопка "ЗАНОВО" перезапускает раунд.

## Как залить на GitHub с телефона (без ПК)

1. Создай новый пустой репозиторий на github.com (кнопка "New repository",
   ничего не отмечай — ни README, ни .gitignore).
2. Проще всего работать через приложение **Working Copy** (iOS) или
   **Termux + git** / **GitJournal** / любой git-клиент под Android,
   который умеет `git init` → `git add` → `git commit` → `git push`
   и сохраняет структуру папок (это важно — обычная загрузка файлов
   через сайт GitHub с телефона часто теряет вложенные папки типа
   `.github/workflows/`).
3. Залей содержимое этого архива целиком, сохранив структуру папок.

## Как получить APK

После пуша в ветку `main` (или `master`) в репозитории откроется вкладка
**Actions** → workflow `build-android-apk` начнёт собираться сам.
Сборка идёт 3–7 минут. По завершении внизу страницы workflow будет
**Artifacts → nextbot-school-apk** — скачай архив, внутри лежит `.apk`.

Установка: скачай `.apk` на телефон, открой — Android спросит про
"установку из неизвестных источников", разреши для браузера/файлового
менеджера.

## Если сборка упала (красный крестик)

Открой упавший workflow → сверху будет лог. Нажми на шаг с крестиком —
там будет текст ошибки. Просто скопируй его сюда (можно скриншотом),
я поправлю.

## Управление

- Левая половина экрана снизу — джойстик (ходьба).
- Правая половина экрана сверху — свайп для поворота камеры.
- Кнопка "БЕЖАТЬ" (удерживать) — спринт.
- Кнопка "ПРЫЖОК".
